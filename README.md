# Containeria

An open-source, low-memory container app for macOS: containers, Compose, Kubernetes, Linux machines
and a built-in database browser, on a Colima engine.

This repository holds the design stage: an interactive HTML prototype of every screen, plus the plan.

- Open `design/index.html` in Chrome or Safari. No build step, no server.
- [`DESIGN.md`](DESIGN.md): design system and rules.
- [`FEATURES.md`](FEATURES.md): every feature, mapped to the part of the engine that makes it work.
